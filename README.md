# README
Three Tier Distributed Web Application. Capstone project for CNT 4714 at UCF Screenshots are in the screenshots folder.

The idea was to develop a full stack webapp that used Tomcat as the server, java servlets as middleware, and JDBC to handle database connections.

This project was developed a long time ago. I wasn't thinking about portability or future use.  You can see what I managed to get done but I haven't provided a way for you to run it yourself.

Screenshots are in the top level in a folder by the same name.
